## Part 2: Bug Fixes by Module

### A. `core/agent/AgentLoop.kt`

1. **Local tool-call parser breaks nested JSON** (Critical): Replace non-greedy `.*?` regex with balanced-brace scanning for fenced and bare JSON forms.
2. **Tool execution on Main dispatcher** (High): Wrap `toolRegistry.executeTool(...)` in `withContext(Dispatchers.IO)` in both cloud and local agent paths.
3. **Native engine never released** (High): Wrap local generation in `try/finally { localEngine.unloadModel() }`.
4. **Local 8-token cap** (Medium): Remove `.coerceAtMost(LOCAL_MAX_TOKENS)` and `LOCAL_CONTEXT_SIZE` cap — use user config or sensible defaults (2048/512).
5. **Unknown tool bypasses permission** (Medium): Return `ToolPermissionCheckResult.Blocked("Unknown tool")` when `tool == null`.
6. **LocalStopGeneration as CancellationException** (Medium): Replace with a private `RuntimeException` subclass.
7. **LocalPromptSessionCache unsynchronized** (Medium): Replace mutable singleton vars with a `ConcurrentHashMap` keyed by `(chatId, modelPath)`.
8. **approvalCallback no timeout** (Medium): Add `withTimeout` around `approvalCallback` with deny-on-timeout.
9. **Max iterations emitted as Error** (Medium): Add `AgentEvent.IterationLimit` or emit as warning, not error.
10. **findLocalStopIndex startIndex=1 + O(n²)** (Low): Start at 0, track search cursor.
11. **shouldStopAfterLocalSentence** (Low): Document/configure behavior.
12. **LocalToolCallParser fallback** (Low): Only treat content as tool call if it starts with `{`, ends with `}`, and parses to object with `name`.
13. **ToolPermissionStore_companion naming** (Low): Rename to `ToolPermissionChecks` and move logic to model module.
14. **parseChatCompleteContent swallows exceptions** (Low): Return a sentinel error string on parse failure.
15. **buildLocalPrompt system prompt** (Low): Use consistent system prompt with tool definitions.

### B. `core/providers/openai/OpenAiStreamClient.kt`

16. **SSE error responses silently swallowed** (Critical): In `parseChunk`, detect `root["error"]` and return `StreamChunk(error=...)`. In `onEvent`, emit error chunk instead of silently catching.
17. **Channel close race** (Critical): Guard with `@Volatile var closed`, close once, ignore events after close.
18. **chatComplete blocks main thread** (High): Wrap `execute()` in `withContext(Dispatchers.IO)`.
19. **Unbounded response body reads** (High): Cap body reads with a bounded input stream reader (e.g., read at most N bytes).
20. **Ollama domain substring match** (Medium): Compare host exactly via `URI(primary).host`.
21. **parseChunk tool_calls not wrapped** (Medium): Wrap each `tc` parse in `runCatching`, skip bad elements.
22. **Custom Authorization header duplication** (Low): Only auto-add `Bearer` if `customHeaders` doesn't contain `Authorization`.
23. **fetchModels empty-vs-error ambiguity** (Low): Distinguish 200-empty from error.
